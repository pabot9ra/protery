# Protery

Курсовой проект по ППОИС в БГУИР. Protery — трекер калорий и белка для iOS.
В приложении планируется ввод еды фразой или по фото и дневник с хранением
на устройстве. Требования описаны в [docs/requirements.md](docs/requirements.md).

## Как запустить демо

Пока готова консольная версия на C++. Она ищет продукты по названию и
синонимам. Можно указать вес перед названием («150 г», «150г», «0,15 кг»)
или оставить стандартную порцию.

```sh
cmake -S . -B build
cmake --build build
./build/protery_demo data/foods.txt '200 г гречки и куриная грудка'
```

Для сборки демо нужны CMake 3.20+ и компилятор с поддержкой C++17.

### Как добавить продукт

В `data/foods.txt` каждая строка описывает один продукт:

```text
название|синонимы через ;|ккал на 100 г|белок на 100 г|порция в граммах
```

Указывайте состояние продукта в названии, если оно влияет на пищевую
ценность, например «гречка варёная». Синонимы должны быть уникальны во всём
каталоге. Поле синонимов можно оставить пустым. Для дробей подходят точка
и запятая. Строки, начинающиеся с `#`, программа пропускает.
