# Protery

Трекер питания для iOS, который считает только калории и белок. Еду можно ввести фразой на русском («200 г гречки и куриная грудка») или сфотографировать блюдо. Вся обработка выполняется на устройстве.

Проект по ППОИС, БГУИР.

## Возможности

- Ввод еды обычной фразой с автоматическим распознаванием продуктов и количеств.
- Распознавание блюда по фото.
- Дневник за день и статистика потребления белка.

## Что на каком языке

**C — библиотека `NutritionCore`:** работа с UTF-8 и кириллицей, нормализация текста, разбор фраз (продукты, числа, единицы), база продуктов и нечёткий поиск по ней, расчёт калорий и белка, статистика, юнит-тесты.

**Swift — iOS-приложение:** интерфейс на SwiftUI, обёртка над C-библиотекой, камера, распознавание фото через Core ML, хранение данных.

**Python — вне приложения:** обучение модели для фото и оценка качества.

## Структура

```
App/             # iOS-приложение (Swift)
NutritionCore/   # C-библиотека
data/            # база продуктов
ml/              # обучение модели (Python)
docs/            # требования, UML, отчёт
```

## Сборка

Нужны macOS и Xcode. Откройте проект в Xcode, `NutritionCore` подключается как локальный Swift Package.
