# Требования к Protery

## 1. Назначение
Protery — трекер питания для iOS, который считает только калории и белок. Он предназначен для людей, которые следят за потреблением белка: занимаются спортом, набирают массу или худеют.

От аналогов Protery отличается двумя вещами. Еду можно записать обычной фразой на русском языке, без поиска по каталогу. Вся обработка выполняется на устройстве, без интернета.

## 2. Функциональные требования
ФТ-1. Ввод еды текстовой фразой на русском языке.
ФТ-2. Выделение из фразы продуктов, количеств и единиц измерения (г, кг, мл, л, шт, ложка, стакан, порция). Число можно записать цифрами (`200`, `1,5`) или словами («два», «полтора»), до или после названия продукта.
ФТ-3. Поиск продукта в графе знаний с учётом опечаток, падежных окончаний («гречки», «с курицей») и синонимов («куриное филе» = «куриная грудка»).
ФТ-4. Расчёт калорий и белка для каждой позиции и в сумме. Недостающие данные берутся по связям графа:
- вес единицы («1 яйцо» ≈ 55 г, «стакан» = 250 мл);
- порция по умолчанию, если количество не указано;
- родительский узел («является»), если у продукта нет своих значений;
- состав блюда («состоит из»): калории и белок блюда считаются по ингредиентам.
ФТ-5. Распознавание блюда по фотографии. Приложение предлагает 3 наиболее вероятных варианта, пользователь выбирает нужный. Вес подставляется по стандартной порции, и пользователь может его изменить.
ФТ-6. Перед добавлением в дневник пользователь видит распознанные позиции и может исправить продукт или количество.
ФТ-7. Дневник: добавление, изменение и удаление записей. Записи группируются по дням, история прошлых дней сохраняется.
ФТ-8. Цель по белку на день: задаётся вручную или рассчитывается по весу пользователя (1,6 г на кг).
ФТ-9. Статистика: калории и белок за день в сравнении с целью, график белка за 7 дней, средние значения за неделю.

## 3. Нефункциональные требования
НФТ-1. Работа без интернета: вся обработка и хранение данных выполняются на устройстве.
НФТ-2. Платформа: iOS 17+.
НФТ-3. Разбор фразы длиной до 100 символов занимает не более 50 мс.
НФТ-4. Знания о продуктах хранятся в графе знаний (узлы — продукты, блюда и единицы измерения; рёбра — синонимия, «является», «состоит из», вес единицы, порция по умолчанию), который загружается из файла. Вывод по графу детерминирован, языковая модель не используется.
НФТ-5. Логика (граф знаний, разбор фраз, поиск, расчёт, статистика) вынесена в отдельную библиотеку на C++ (`NutritionCore`) с юнит-тестами и C API для вызова из Swift.
НФТ-6. Библиотека корректно обрабатывает кириллицу в UTF-8 и не падает на некорректном вводе (пустая строка, неизвестные слова, битый UTF-8).

## 4. Примеры
| Ввод | Ожидаемый результат |
|---|---|
| «200 г гречки и куриная грудка» | гречка — 200 г; куриная грудка — порция по умолчанию (150 г) |
| «2 яйца и стакан молока» | яйцо — 2 шт (~110 г); молоко — 1 стакан (250 мл) |
| «гречкаа 150» | гречка — 150 г (исправлена опечатка, число после продукта) |
| «полтора банана» | банан — 1,5 шт (~180 г) |
| «творог 5% 180г» | творог 5% — 180 г (единица записана слитно с числом) |
| «абвгд» | продукт не найден, пользователю предлагается ввести его вручную |

## 5. Ограничения
- Учитываются только калории и белок, без жиров, углеводов и микроэлементов.
- Граф знаний ограничен: около 300 распространённых продуктов и блюд.
- Поддерживается только русский язык.
- Вес блюда по фото не определяется: используется стандартная порция.
